F# compiled to WebAssembly GC

Real F# application code compiled to native WasmGC binary by fsharp-wasm. No JavaScript application logic — only a thin JS glue layer (<500 LOC) for browser APIs.

How it works

Each demo is a plain F# project:

<!-- demos/counter/Counter.fsproj -->
<Project Sdk="Microsoft.NET.Sdk">
  <ItemGroup>
    <ProjectReference Include="../../src/FSharpWasmRuntime.fsproj" />
    <Compile Include="Counter.fs" />
  </ItemGroup>
</Project>

Compiled with:

fable demos/counter/Counter.fsproj --lang wasmgc -o demos/counter/

Run node build/build.js to build all demos at once.

Compiler status

The fsharp-wasm compiler is under active development. Features confirmed working:

  • Pure F# numeric / math code (loops, recursion, pattern matching)
  • Direct JS FFI via [<Import>] / nativeOnly
  • Discriminated unions, records, lists
  • Canvas 2D rendering

Features in progress (demos compile; full interactivity pending):

  • Mutable local capture in closures → Elmish event dispatch loop
  • call_indirect / call_ref in binary emitter → event handler callbacks
  • Cross-file function calls for non-library modules
