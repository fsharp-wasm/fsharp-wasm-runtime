How it works

Three small pieces, each replaceable.

1 · fsharp-wasm
The compiler. F# source → typed AST → WasmGC, with exact .NET semantics for integers, floats, strings, printf, generics and structural equality — verified by differential tests against .NET on every commit.
2 · Browser.*
Typed F# modules for the DOM, events, canvas, storage, IndexedDB, workers, WebGPU and more — plus an HTML builder (div { … }) and an Elmish loop. A JS import is an F# function marked nativeOnly; the compiler does the marshalling.
3 · runtime/*.js
Thin glue, one small file per browser API. Strings cross as native JS strings (the engine's string builtins), a closure passed to JS becomes a JS function that re-enters the module. No bridge generator, no shared memory.
let update msg model =
    match msg with
    | Increment -> { model with Count = model.Count + 1 }, Cmd.none
    | Decrement -> { model with Count = model.Count - 1 }, Cmd.none
    | Reset     -> { model with Count = 0 }, Cmd.none

let view model dispatch =
    article {
        h2 "Counter"
        el "p" { class' "count-display"; string model.Count }
        button { onClick (fun () -> dispatch Increment); "+" }
    }

let start () = run "counter-root" { Init = init; Update = update; View = view }
