Widget Editor — fsharp-wasm-ide

A visual editor for FSharp.Graphics widget layouts, written in F# and compiled to WebAssembly GC. The whole interface — palette, design surface, inspector, generated code — is drawn by the module onto one canvas; JavaScript only forwards pointer, key and size events.
