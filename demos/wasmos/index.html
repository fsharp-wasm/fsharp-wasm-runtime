WasmOS

One F# program, four systems. A small desktop — windows you drag, resize, minimise and maximise, a launcher, a menu, five apps — that is Windows, macOS, Android or a Linux desktop with one click. The model is a pure function (it also runs under .NET and is tested there); the module states the DOM, and the page's CSS makes it look like each system. This is what the universal shell of fsharp-wasm-embedded hosts: the same application in the chrome of the device it runs on.
